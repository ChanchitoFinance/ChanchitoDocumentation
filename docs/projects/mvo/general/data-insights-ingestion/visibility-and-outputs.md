# Visibility and Outputs

IDL outputs are scoped by audience.

## Owner Insights

- Full scorecard
- Trends and drivers
- Iteration recommendations

## Public Insights

- Sanitized aggregates
- No user-level or source data
- Non-gameable signals only

## Admin Insights

- Platform-wide health
- Anomaly detection
- Moderation signals

Visibility is enforced at the data layer.
