# Chanchito 4Ps

## Product

**Chanchito** is a mobile-first application designed to eliminate friction in everyday finance management, especially within social contexts. It is tailored for Gen Z users who often engage in group activities, informal loans, and shared expenses.

### Key Problems We Address:

1. **Untracked Debts:** Forgetting who owes whom money leads to awkward situations.
2. **Expense Logging Fatigue:** Busy lives make regular financial tracking unrealistic.
3. **Group Expense Headaches:** Manual bill splitting causes errors and tension.
4. **Opaque Shared Pots:** Lack of visibility in joint accounts or savings.
5. **Subscription Confusion:** Forgotten renewals and uneven shared subscription payments.

### Proposed Solutions:

* Streamlined event and bill planning (asados, dinners, hangouts).
* Automated cost splitting and tracking of payments.
* Notifications for pot contributors and subscribers.
* Built-in reminders and accountability tools.
* A friendly UX with low cognitive load for fast, on-the-run usage.

### MVP Features:

* Group event planner with RSVP and shared payment calculation.
* Quick-add expenses with minimal input steps.
* “Buy Me a Coffee” QR feature for voluntary support.
* Bug reporting and feedback tools centered on user behavior.

## People

### Target Audience:

* **Gen Z and Millennials** who often share costs and hang out in social settings.
* Users in **Latin America** and other informal cash-sharing cultures.

### Core User Personas:

1. **The Spontaneous Planner:** Loves organizing hangouts but hates following up on payments.
2. **The Quiet Contributor:** Feels uncomfortable asking for what they’re owed.
3. **The Accountability Buddy:** Wants full transparency and real-time updates on pots and subscriptions.
---

## Process

### Design Principles:

* **Behavioral-Centered UX**: Focus on *what users already do*, not what we want them to do.
* **Fast Flows**: Less than 3 taps to log any expense.
* **Minimalist UI**: Clean, focused interfaces.

### Feedback and Support:

* In-app “I need help” trigger that mimics DM behavior.
* Context-aware bug reporting.
* Embedded QR for Buy Me a Coffee support.

## Project

### Phase 1: MVP Scope
* Initial development of on-the-go interfaces and functionality.
* User accounts with default products and categories that users can save.
* Deploy and validate core functionality.
* Collect user feedback, fix bugs, document findings, and plan the next increment.

### Tools & Stack:

* **Frontend**: Flutter (cross-platform mobile)
* **Backend**: C# (.NET)
* **Database**: SQLite
* **CI/CD**: GitHub Actions

### Milestones:
* Week 1-2: UI layout and mobile navigation flows.
* Week 3-4: Backend endpoints for user accounts, categories, and products.
* Week 5: SQLite integration and local testing.
* Week 6: First deployment and QA pass.
* Week 7: Feedback collection and prioritization.
* Week 8: Bug fixing, documentation, and learning sprint.
